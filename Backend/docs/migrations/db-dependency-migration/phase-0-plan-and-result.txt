## Safety-net policy

For Phase 2 (Commit 2) and Phase 3 (Commit 3) the following must hold vs this
baseline:

1. **OpenAPI snapshot byte-identical** — generator deps don't surface in the schema.
2. **Endpoint inventory identical** — `@router.*` decorator count must match (modulo line-number shifts from removed `with` lines, which are expected).
3. **Coverage `TOTAL` line not lower** than 58%.
4. **pytest pass/fail counts identical or better.**
5. **No new ruff/mypy errors on lines I added or modified** (pre-existing errors elsewhere are OK per `AGENTS.md`).

## Commit 1 scope

Only two files were modified in Commit 1:

- `app/DB/main.py` — added `get_db()` generator dependency and `SessionDep = Annotated[Session, Depends(get_db)]` alias.
- `app/routers/departments.py` — migrated both route handlers (`get_all_departments`, `get_department_by_id`) from `with SessionLocal() as session:` to `session: SessionDep`.

No other files were touched. No test files were modified. No `AGENTS.md` edit yet (that lands in Commit 2 per PLAN.md §6.5).
